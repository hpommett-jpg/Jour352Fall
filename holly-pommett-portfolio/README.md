# Holly Pommett Portfolio

Personal portfolio site. Two pages:

- `index.html`: homepage / resume
- `clips.html`: video and graphic design samples

## Publish on GitHub Pages

1. Create a new public repo on GitHub (for a clean URL, name it `<your-username>.github.io`).
2. Upload everything in this folder to the root of the repo (drag and drop on the repo page works; keep the folder structure).
3. Go to **Settings > Pages**, set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. The site goes live in a minute or two at `https://<your-username>.github.io/` (or `https://<your-username>.github.io/<repo-name>/`).

## Editing

- Text: edit `index.html` and `clips.html` directly.
- Styles: `css/style.css`.
- Swap the headshot by replacing `assets/images/headshot.jpg` (same file name).
- To add a clip, copy one `<section class="clip">` block in `clips.html` and change its contents.
